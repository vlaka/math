# Math

Приложение для изучения математики (4 класс): сложение, вычитание, умножение, деление.

## Запуск

```bash
npm install
npm run dev
npm run icons   # перегенерировать PNG-иконки
```

## Режимы

- **Изучение** — показать ответ на экране
- **Тренировка** — голосовой ввод или цифровая клавиатура
- **Квест** — серия примеров с таймером и звёздами

## Языки

Русский и иврит (интерфейс + распознавание ответов).
